# M 位仿真分配表

## 用法
1. OB1 Network 0 写桥接代码（见下方）
2. 监控表中添加所有 M 地址
3. 按步骤手动改 M 位值，模拟传感器信号

## 仿真操作流程

### 状态初始化（开机默认值）

把监控表里这些 M 位设成 1：
```
M100.2, M100.3, M101.0, M101.2, M101.4, M101.6, M102.0, M102.2,
M103.0, M103.2, M103.4, M104.0, M104.3, M105.1, M105.3, M105.5, M105.6
```
其余为 0。`M100.6` 设为 1 启用仿真。

### 步骤 1：启动

```
M100.0 = 1   运行准备
M100.1 = 1   启动按钮
M100.5 = 1   自动模式
→ FB100: S1→S2 开始跑
```

### 步骤 2：模拟气缸动作

FB100 输出驱动气缸后，手动改对应 M 位模拟气缸到位：

| FB100 输出 | 改这个 M 位 | 模拟什么 |
|-----------|------------|---------|
| 前阻挡伸出 | M101.1=1, M101.0=0 | 前阻挡到位 |
| 工位阻挡伸出 | M101.3=1, M101.2=0 | 工位阻挡到位 |
| 定位伸出 | M101.5=1, M101.4=0 | 定位到位 |
| 移载下降 | M103.3=1, M103.2=0 | 升降下限位 |
| 夹爪夹紧 | M103.5=1, M103.4=0 | 夹紧到位 |
| 夹爪松开 | M103.4=1, M103.5=0 | 松开到位 |
| 升降上升 | M103.2=1, M103.3=0 | 升降上限位 |
| 平移伸出 | M103.1=1, M103.0=0 | 平移伸出到位 |
| 平移缩回 | M103.0=1, M103.1=0 | 平移缩回到位 |
| 二次定位横+纵 | M102.1=1, M102.3=1 | 二次定位到位 |
| 压头下降 | M105.2=1, M105.1=0 | 压头降位 |
| 压头上升 | M105.1=1, M105.2=0 | 压头升位 |
| 旋转压位 | M105.4=1, M105.3=0 | 旋转到压位 |
| 旋转回位 | M105.3=1, M105.4=0 | 旋转回原位 |

### 步骤 3：拧螺丝模拟

FB101 S5(真空吸)→S6(Z上升)→S7(切孔位)→S8(Z下降)→S9(电批启动)：

```
M102.4 = 1    螺丝振盘到位 (模拟有螺丝可吸)
M102.5 = 1    真空检知 (吸到螺丝)
→ 等FB101跑

M104.1 = 1    电批启动反馈
等3秒
M104.2 = 1    电批刹车=扭矩到达 (锁紧完成)
→ 等FB101完成

M104.2 = 0    电批刹车清零 (FB101完成S10后)
M104.1 = 0    电批停止
M102.5 = 0    真空关 (FB101关真空阀后)
```

### 步骤 4：送出模拟

FB102 S2(移载伸)→S3(降)→S4(夹)→S5(升)→S6(缩回)→S7(降)→S8(松)→S9(升)→S10(释放定位)→S11(释放阻挡)→S12(送出)：

```
同上表格，按FB102的输出顺序逐个改 M 位模拟传感器到位
最终FB100 S19等 bAck_OutDone=1 → FB100回到S1
```

---

## 注意事项

1. 每个传感器都是**双向**的：到位=1, 原位=0
2. 每次改 M 位后等 FB 走到下一步再改下一个
3. 如果某个步卡住了，打开 FB 看当前在哪个步，缺哪个传感器信号
4. 调试时可以先只跑 FB100（接收工件），确认气缸流程正确后再跑 FB101
