## 关键说明

### 伺服 INP 信号必须跟踪

FB_ServoGotoHome 和 FB_ServoGotoPos 内部读取 I 地址判断到位：
- 回零后必须置 `%I0.2 / %I0.5 / %I1.0 = TRUE` (原点)
- 定位后必须置 `%I1.4 / %I1.7 / %I2.2 = TRUE` (INP)
- 下次运动前必须先把 INP 复位为 FALSE，再延迟置 TRUE

### 时间间隔参考

| 动作 | 间隔 |
|------|------|
| 触发回零 → 原点信号 | 2s |
| 触发 MoveX/Y → INP | 2s |
| 触发 MoveZ → INP | 2s |
| 气缸伸出/缩回 | 1.5~2s |
| 电批拧紧 | 3s |
